Connection and synchronization

Google Sheets → Supabase: your existing five-minute trigger imports new spreadsheet records. App → Supabase: manual entries save immediately. Supabase → Google Sheets: use the optional companion Apps Script in the included setup instructions; it appends new manual records but does not reconcile edits or deletions. There is no live cross-device update until you refresh.

Only manually entered transactions can be edited or deleted here. Records imported from Google Sheets must be corrected in the source sheet. Manually entered records already exported to Sheets are not updated or removed there by this version; reconcile those rows manually. This dashboard reads up to 5,000 recent transactions; for larger datasets, add server-side reporting and pagination.
